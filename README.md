# لمعة | Lam’ah — الموقع الرسمي

موقع استشارات الأمن والسلامة، عربي/إنجليزي، متعدد الصفحات، مبني وفق ملف التخطيط المعتمد (The Safety Framework).

## محتويات الموقع
- الرئيسية، من نحن، الخدمات، المنهجية، تواصل معنا.
- صفحات مستقلة للخدمات الثلاث: إعداد خطط الأمن والسلامة؛ تقييم المخاطر وتحليل التهديدات؛ الاستشارات الأمنية وحماية المنشآت.
- نسخة إنجليزية كاملة تحت `/en/`.
- رسوم SVG أصلية توضيحية، هوية كحلي/أزرق سماوي/أبيض/فضي، ولا توجد عناصر ذهبية.
- خطوط محلية داخل `assets/fonts` لتجنب الاعتماد على Google Fonts وقت التشغيل.

## التشغيل محليًا
1. فك ضغط الحزمة.
2. افتح الطرفية داخل مجلد `site`.
3. شغّل: `python -m http.server 8000`
4. افتح `http://localhost:8000`.

يمكن أيضًا فتح `index.html` مباشرة للمعاينة، لكن تشغيل خادم محلي أفضل لاختبار الروابط.

## النشر على GitHub Pages
1. أنشئ مستودع GitHub جديدًا.
2. ارفع **محتويات مجلد site** إلى جذر المستودع (بحيث يكون `index.html` في الجذر).
3. من Settings → Pages اختر Deploy from a branch ثم `main` و`/ (root)`.
4. احفظ وانتظر اكتمال النشر.

> ملاحظة: الروابط مضبوطة للنشر على جذر النطاق أو GitHub Pages عند رفع الموقع إلى جذر المستودع. إذا رغبت بالنشر داخل مجلد فرعي باسم المستودع، يلزم ضبط base path قبل النشر.

## قبل الإطلاق العام
- أضف البريد والهاتف ووسيلة التواصل الرسمية في صفحة التواصل والتذييل.
- نموذج التواصل غير مفعّل للإرسال؛ لا توجد بيانات اتصال أو خدمة استقبال نماذج معتمدة حتى الآن.
- راجع النصوص التعريفية النهائية واعتمدها من صاحب المشروع.
- استبدل علامة الشعار النصية/الرمزية بالملف الرسمي الشفاف متى توفر بصيغة SVG أو PNG منفصلة.

## ملاحظات المحتوى
لا يتضمن الموقع ادعاءات عن تراخيص أو شهادات أو عملاء أو إنجازات أو تغطية تشغيلية دولية غير موثقة. مقر الشركة في الرياض، واللغة الإنجليزية تعكس جاهزية تواصل دولية دون ادعاء وجود عمليات في دول أخرى.

## الخطوط المرفقة
ملفات Inter مضمّنة محليًا للإنجليزية. وبما أن ملفات IBM Plex Sans Arabic المعتمدة لم تكن ضمن الأصول المتاحة وقت تجهيز هذه الحزمة، أُرفق Noto Sans Arabic محليًا كبديل عربي واضح بدل تحميل خط خارجي أو الادعاء بتضمين IBM Plex. يمكن استبدال ملفي Noto بملفات IBM Plex Sans Arabic المرخّصة لاحقًا مع تحديث تعريفات `@font-face` في `assets/site.css`. تراخيص الخطوط مرفقة بجانب الملفات.
